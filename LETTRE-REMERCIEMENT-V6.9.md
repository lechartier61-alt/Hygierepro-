# Lettre de remerciement LGY

Chaque commande possède désormais un bouton **Lettre de remerciement** dans l’administration.

La lettre contient :

- le logo LGY ;
- le nom du client ;
- un message de remerciement ;
- la mention de la célèbre brioche Madeleine ;
- la mention « faite maison avec des produits fermiers de Mayenne » ;
- les coordonnées de la boulangerie ;
- un cadre « Fait le » ;
- un cadre réservé à la signature.

Le document peut être imprimé ou enregistré en PDF depuis le navigateur.

Le titre, le message et le libellé de signature sont modifiables dans :

**Administration → Paramètres → Lettre de remerciement**
