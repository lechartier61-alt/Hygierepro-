# HygieSafe v6.8.4 — Scanner DLC simplifié

Version prête à déployer basée sur la v6.8.3 PWA.

La nouveauté principale est le scan DLC avec **1 ou 2 photos maximum**, cadrées uniquement sur la zone **DLC + numéro de lot**. Une deuxième photo peut être ajoutée si les deux informations sont imprimées à des endroits différents de l'emballage. Les preuves sont liées au produit et conservées dans la traçabilité.

Cette version conserve l'installation PWA téléphone/PC, le scanner produit intelligent, les journées guidées, les équipements, le pilotage, le multisite, Stripe et les fonctions précédentes.

Commencer par `START-HERE-v6.8.4.md` puis `PRODUCTION-CHECKLIST-v6.8.4.md`.
