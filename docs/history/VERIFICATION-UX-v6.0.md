# Vérification UX — HygiePro v6.0

## Principe retenu

Toutes les options métier sont conservées, mais elles ne sont plus montrées en même temps.

## Nouveau parcours utilisateur

1. créer mon entreprise ;
2. essai 14 jours activé ;
3. terminer 5 étapes d'onboarding ;
4. arriver sur Aujourd'hui ;
5. cliquer sur Commencer ;
6. utiliser Scanner à tout moment ;
7. ouvrir Menu uniquement pour les fonctions secondaires.

## Navigation principale

- Aujourd'hui
- Contrôles
- Scanner
- Traçabilité
- Menu

## Équipe

Il n'existe plus d'écran de profils avec PIN. Chaque personne possède son accès personnel. Le gérant invite les salariés ; l'invité définit son mot de passe puis se connecte normalement.

## Admin

L'administration n'est pas annoncée sur la page publique. Elle possède son propre écran de connexion et exige le 2FA avant l'accès aux données de pilotage.

## Points à contrôler sur appareils réels

- iPhone / Safari ;
- Android / Chrome ;
- tablette portrait/paysage ;
- ordinateur 1366 px et plus ;
- appareil photo pour DLC/code-barres ;
- mode réseau faible / reprise de synchronisation.
