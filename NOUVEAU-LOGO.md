# Nouveau logo LGY

Le nouveau logo est intégré dans :

- la barre de navigation ;
- le pied de page ;
- la page d’accueil ;
- le favicon du navigateur ;
- l’icône iPhone ;
- les icônes Android et PWA ;
- l’image de partage Open Graph ;
- le cache hors ligne du service worker.

## Déploiement

```bash
git add .
git commit -m "Intégration du nouveau logo LGY"
git push origin main
```

Railway redéploiera automatiquement le projet.
