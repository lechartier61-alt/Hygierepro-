# HygieSafe v6.5.7 — Durcissement production

- Employé : modification limitée à ses propres saisies compatibles pendant 15 minutes ; pointeuse non modifiable.
- Chaque correction enregistre l'état avant/après dans le journal d'audit.
- Suppression média : preuve rattachée non supprimable ; employé limité à son propre fichier non utilisé pendant 15 minutes ; gérant/responsable uniquement sinon.
- Sessions Scanner Pro : un employé ne peut plus modifier/terminer la session d'un collègue.
- File hors-ligne v2 liée à l'utilisateur et à l'entreprise ; aucune synchronisation vers un autre compte.
- Open Food Facts : consultation à la demande sans cache persistant de fiche produit ; attribution ODbL conservée.
- Mémoire produit locale : uniquement code-barres + nom opérationnel confirmé pour les données issues d'une source externe.
- Anciennes fiches externes mémorisées nettoyées par migration 028.
- CGV : taux des pénalités de retard explicité et indemnité de 40 € maintenue.
- Confidentialité : caractère obligatoire, origine des données et décisions automatisées précisés.
- Coordonnées légales : e-mail + téléphone obligatoires lors de l'enregistrement côté Admin.
- Domaine d'exemple corrigé vers www.hygiesafe.com et SMTP_FROM vers mail.hygiesafe.com.
- Accueil : « Sauvegarde serveur automatique » remplacé par « Sauvegarde ZIP complète à télécharger ».
