# LGY.fr V6.6

## Administration

- bouton **Tester une commande** ;
- historique complet des commandes ;
- facture imprimable pour chaque commande ;
- bordereau d'envoi avec logo, nom et adresse du client ;
- export CSV de toutes les commandes ;
- sauvegarde JSON complète : commandes, clients, produits, promotions, paramètres et journal d'audit ;
- informations légales de facturation paramétrables : raison sociale, SIRET, TVA et texte de bas de facture.

## Navigation

- « Nos gâteaux » est remplacé par « Notre boutique ».

## Important

Pour une facture juridiquement complète, renseignez les informations légales dans :
**Administration > Paramètres > Informations légales et facturation**.
